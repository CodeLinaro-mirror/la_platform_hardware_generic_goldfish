**Role:** Strongly-Typed V2 gRPC Service Implementations (`android.emulation.v2.*`)
**Location:** `emulator/plugin/grpc/services/v2/`
**Build Targets:** `@goldfish//emulator/plugin/grpc/services/v2:v2_services`, `@goldfish//emulator/plugin/grpc/services/v2:battery_service`, `@goldfish//emulator/plugin/grpc/services/v2:battery_service_test`, `@goldfish//emulator/plugin/grpc/services/v2:sensors_service`, `@goldfish//emulator/plugin/grpc/services/v2:sensors_service_test`, `@goldfish//emulator/plugin/grpc/services/v2:location_service`, `@goldfish//emulator/plugin/grpc/services/v2:location_service_test`, `@goldfish//emulator/plugin/grpc/services/v2:rtc_service`, `@goldfish//emulator/plugin/grpc/services/v2:rtc_service_test`, `@goldfish//emulator/plugin/grpc/services/v2:capabilities_service`, `@goldfish//emulator/plugin/grpc/services/v2:capabilities_service_test`, `@goldfish//emulator/plugin/grpc/services/v2:operations_service`, `@goldfish//emulator/plugin/grpc/services/v2:operations_service_test`, `@goldfish//emulator/plugin/grpc/services/v2:hypervisor_service`, `@goldfish//emulator/plugin/grpc/services/v2:hypervisor_service_test`, `@goldfish//emulator/plugin/grpc/services/v2:input_service`, `@goldfish//emulator/plugin/grpc/services/v2:input_service_test`, `@goldfish//emulator/plugin/grpc/services/v2:system_service`, `@goldfish//emulator/plugin/grpc/services/v2:system_service_test`

## Overview
Implements the next-generation `android.emulation.v2` gRPC services defined in `@aemu//protos/services_v2` (`hardware/google/aemu/protos/services_v2/DESIGN.md`) and registers them with the main QEMU gRPC server (`@goldfish//emulator/plugin/grpc:grpc`).

## Key Sub-Components, Files & Symbols (`namespace goldfish::grpc::v2`)
- **Service Registration (`:v2_services`)**:
  - `include/goldfish/grpc/v2/v2_services.h` & `v2_services.cc`:
    - `CreateV2Services(AvdUniverse& avd_universe, VmOperations* vm_operations)` — Instantiates `CapabilitiesServiceImpl`, `SensorsServiceImpl(avd_universe.GetSensorsPhysicalModel())`, `SystemServiceImpl`, `BatteryServiceImpl`, `InputServiceImpl`, `LocationServiceImpl`, and (when `vm_operations` is non-null) `OperationsServiceImpl` and `HypervisorServiceImpl`, called by `CreateServices` in `emulator/plugin/grpc/grpc.cc` with `avd_universe.GetVmOperations()`.
- **V2 Battery Service (`:battery_service`, test `:battery_service_test`)**:
  - `battery/battery_service_impl.h`, `battery/battery_service_impl.cc`, `battery/battery_service_impl_test.cc` (`BatteryServiceImpl`).
  - Implements `android.emulation.v2.BatteryService` (`@aemu//protos/services_v2:battery_service_cc_grpc`) over `ObservableBattery` (`avd_universe.GetBattery()`), covering battery charge level, power source, charging lifecycle state, and thermal health observation & mutation (`GetBatteryState`, `StreamBatteryState`, `UpdateBatteryState`). Rejects requests with `FAILED_PRECONDITION` when the device has no battery subsystem (`!hw.hw_battery`) or when a charger/health mode is unsupported by `goldfish_battery` (`CHARGER_SOURCE_AC` / `CHARGER_SOURCE_NONE`), and enforces `ACCESS_MODE_READ_ONLY` when configured.
- **V2 Location Service (`:location_service`, test `:location_service_test`)**:
  - `location/location_service_impl.h`, `location/location_service_impl.cc`, `location/location_service_impl_test.cc` (`LocationServiceImpl`).
  - Implements `android.emulation.v2.LocationService` (`@aemu//protos/services_v2:location_service_cc_grpc`) over `goldfish::avd_universe::gps::ObservableLocation`, providing `GetLocationState`, `StreamLocationState` (`StateStreamWriter`), partial `UpdateLocationState` mutations, and server-paced `PlayRoute` waypoint playback on `globalEventLoop()`.
- **V2 Input Service (`:input_service`, test `:input_service_test`)**:
  - `input/input_service_impl.h`, `input/input_service_impl.cc`, `input/input_service_impl_test.cc` (`InputServiceImpl`).
  - Implements `android.emulation.v2.InputService` (`@aemu//protos/services_v2:input_service_cc_grpc`) on the shared `IInputDispatcher` (`avd_universe.GetInputDispatcher()`), with one `DispatcherSession` per input source; `IMultiDisplay` only validates display IDs. Supports paced batch gestures (`SendInputEvents`, whose sessions persist across calls), interactive streams with `x-client-id` source derivation whose sessions release their input when the stream ends (`StreamInputEvents`), and live observation of the dispatcher's activity, including WebRTC v2 input (`StreamInputActivity`).
- **V2 System Service (`:system_service`, test `:system_service_test`)**:
  - `system/system_service_impl.h`, `system/system_service_impl.cc`, `system/system_service_impl_test.cc` (`SystemServiceImpl`).
  - Implements `android.emulation.v2.SystemService` (`@aemu//protos/services_v2:system_service_cc_grpc`) over `GuestStatus`, `GrpcNotificationEventSource`, `VmOperations`, `ClipboardChannel`, and `ObservableFingerprintSensor`, covering OS lifecycle & reboot (`GetSystemState`, `StreamSystemState`, `RebootDevice`), guest clipboard synchronization (`GetClipboardState`, `StreamClipboardState`, `UpdateClipboardState`), and biometric fingerprint injection (`InjectFingerprint`).
- **V2 Operations Service (`:operations_service`, test `:operations_service_test`)**:
  - `operations/operations_service_impl.h`, `operations/operations_service_impl.cc`, `operations/operations_service_impl_test.cc` (`OperationsServiceImpl`, `OperationEntry`, `MetadataRefresher`).
  - Thread-safe AIP-151 `google.longrunning.Operations` registry (`GetOperation`, `ListOperations`, `WaitOperation`, `DeleteOperation`, `CancelOperation`) and programmatic lifecycle methods (`StartOperation`, `UpdateOperationMetadata`, `SetMetadataRefresher`, `CompleteOperation`, `FailOperation`).
- **V2 Hypervisor Service (`:hypervisor_service`, test `:hypervisor_service_test`)**:
  - `hypervisor/hypervisor_service_impl.h`, `hypervisor/hypervisor_service_impl.cc`, `hypervisor/hypervisor_service_impl_test.cc` (`HypervisorServiceImpl`).
  - Implements `android.emulation.v2.HypervisorService` (`@aemu//protos/services_v2:hypervisor_service_cc_grpc`) over `android::goldfish::VmOperations` and `OperationsServiceImpl`, covering VM lifecycle RPCs (`GetVmState`, `StreamVmState`, `PauseVm`, `ResumeVm`, `ResetVm`, `HardResetVm`, `StopVm`) and snapshot management RPCs (`ListSnapshots`, `GetSnapshot`, `UpdateSnapshot`, `CreateSnapshot`, `RestoreSnapshot`, `DeleteSnapshot`, `SetQuickbootTarget`, `ExportSnapshot`, `ImportSnapshot`).
  - Subscribes to loop-bound `VmOperations::RunStateEvents()` and `VmOperations::SnapshotEvents()` (without blocking on the BQL inside event-loop callbacks), correlates explicit `CreateSnapshot`/`RestoreSnapshot` RPCs and implicit hypervisor saves/loads (e.g. quickboot exit-save, `-loadvm`) into `OperationsServiceImpl` LROs, refreshes in-flight `SnapshotOperationMetadata` via `GetSnapshotProgress()`, and streams every snapshot phase payload (`PREPARING`, `TRANSFERRING`, completion) through `StreamVmState` (`SAVING_SNAPSHOT`, `RESTORING_SNAPSHOT`, and `SHUTTING_DOWN` during quickboot exit-saves).
- **V2 Sensors Service (`:sensors_service`, test `:sensors_service_test`)**:
  - `environment/sensors_service_impl.h`, `environment/sensors_service_impl.cc`, `environment/sensors_service_impl_test.cc`.
  - `SensorsServiceImpl` (and `SensorsServiceBase`) — Implements `android.emulation.v2.SensorsService` (`GetSensorsState`, `StreamSensorsState`, `UpdateSensorsState`, `StreamSensorsUpdates`, `GetPostureState`, `StreamPostureState`, `UpdatePostureState`, `ApplySensorsUpdate`, `BuildSensorsState`, `BuildPostureState`) over `goldfish::sensors::PhysicalModel` (`@goldfish//emulator/libs/sensors:physical_model` in `emulator/libs/sensors/physical_model.cc`).
  - Also invoked directly in-process by the WebRTC `sensors_v2` DataChannel via `CreateInProcessInputSenderFactory` (`@goldfish//emulator/plugin/grpc/services:in_process_rtc_service`).
- **V2 WebRTC Signaling Service (`:rtc_service`, test `:rtc_service_test`)**:
  - `webrtc/rtc_service_impl.h`, `webrtc/rtc_service_impl.cc`, `webrtc/rtc_service_impl_test.cc`.
  - `RtcServiceImpl` (`SendJsepMessage`, `ReceiveJsepMessageStream`) — Bridges `android.emulation.v2.RtcService` (`@aemu//protos/services_v2:webrtc_service_cc_grpc`) to `goldfish::videobridge::Switchboard` (`@goldfish//emulator/videobridge:videobridge_core`).
  - `ParseSwitchboardJsonToJsep` and `SerializeJsepToSwitchboardJson` — Convert between Switchboard JSON (unwrapping nested `candidate` and `sdp` envelopes) and `android::emulation::v2::JsepMessage` protobufs.
- **V2 Capabilities Discovery Service (`:capabilities_service`, test `:capabilities_service_test`)**:
  - `discovery/capabilities_service_impl.h`, `discovery/capabilities_service_impl.cc`, `discovery/capabilities_service_impl_test.cc` (`CapabilitiesServiceImpl`).
